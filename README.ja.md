# natural_block

[English](README.md)

普通の文章をそのまま通す、Dart 向けの軽量マークアップ言語です。
`natural_block` は、レイアウト（ブロック、横並び、表、寄せ）、意味に基づく装飾
（大きさ、トーン、強調）、コードをそのまま書く区間を、ウィジェットに対応づけ
られる構文木に変換します。`C++`、`100%`、`a > b`、`10~20`、`you@example.com` は
エスケープ不要です。

木を Flutter で描くには
[natural_block_flutter](https://github.com/SugaiMasayoshi/natural_block_flutter)
を使います。

## はじめに

```
dart pub add natural_block
```

natural_block のファイルの拡張子は `.nblk` です。VS Code と Open VSX には、色付けの拡張
[natural_block](https://github.com/SugaiMasayoshi/natural_block_editors) があります。

## 使い方

```dart
import 'package:natural_block/natural_block.dart';

void main() {
  final document = NaturalBlockParser.parse('^:!Danger Zone^:%Safe Zone^');
  print(document);
}
```

`parse` は例外を投げず、`DocumentNode` を返します。木は変更できず、構造で比較
されます。

- `DocumentNode` は `ColumnNode` と `RowNode` を持ちます。`RowNode` はセルとして
  `ColumnNode` を持ちます。
- `ColumnNode` は中身として `TextNode`、`RawNode`、`TableNode` を持ちます。
- `TextNode` は `TextSpanNode`（`SpanDecoration` 付きの文字）と `RawSpanNode` を
  持ちます。
- `TableNode` は `TableCellNode` からなる `TableRowNode` を持ち、`columns` に各列
  の寄せを持ちます。

どのノードも、読み取った箇所を `start` と `end` に持ちます。位置は、改行を
`\n` にそろえ、最後の改行を除いたソースで数えます。このソースは
`normalizeSource` で得られます。比較に位置は含みません。`descendants` は、その
ノードより下にあるすべてのノードを、書かれた順に返します。

```dart
final source = ':@page:@';
final document = NaturalBlockParser.parse(source);
for (final node in document.descendants) {
  if (node case TextSpanNode(:final start?, :final end?)) {
    print(normalizeSource(source).substring(start, end));
  }
}
```

## 構文

### レイアウト

| 記号 | 意味 | 例 |
|---|---|---|
| `<` `=` `>` | 行頭で、新しいブロックを開く。先頭寄せ、中央寄せ、末尾寄せ | `=見出し` |
| `^` | 行頭で、横並びの行を開く。セルを `^` で区切り、`^` で閉じる | `^左^右^` |
| `~` | 行頭かセルの頭で、`^...^` の行からなる表を開く。行頭の `~` で閉じる | 下の例 |

- ブロックは、`<` `=` `>` `^` で始まる行の手前まで続きます。それ以外の行は、
  空行も含めてそのブロックに入ります。改行は文字の一部で、空白は削られません。
- 横並びの行は、行末の `^` か文書の終わりで閉じます。1つのセルに複数行を書け
  ます（`^左\n2行目^右^`）。空のセルも場所を取るので、`^左^^右^` では `右` が
  反対の端に押し出されます。
- 行頭の寄せの記号は、それが開くブロックを寄せます。`^` の直後の記号は、その
  セルを寄せます。`=^A^B^>C^` は、自分で寄せを書いていないセルをすべて中央に
  寄せます。読む記号は1つだけで、`<>a` は先頭寄せの `>a` です。
- 表は、行頭か横並びのセルの頭の `~` で開き、表の中の行頭の `~` か文書の終わり
  で閉じます。表の行は表の外の行と同じように読むので、セルに複数行を書けます。
  行は、表を閉じる行でも終わります。行頭の `^` は省けますが、閉じの `^` は
  省けません。行と行の間の空行は何も作りません。
  空の行は `^^` と書きます。列の寄せは、その列に寄せを書いた最初の行から決まり
  ます。セルに書いた記号は、そのセルだけを上書きします。

  ```
  ~
  <品名    ^>価格^
  りんご   ^  100^
  オレンジ ^   80^
  ~
  ```

- エディタが保存時に付ける、ソースの最後の改行は無視します。

### 装飾

`:` の後に装飾の文字が続くと、クラスタになります。文字は順に効き、装飾は行末か
次のブロックまで続きます。

| クラスタ | 意味 |
|---|---|
| `:+` `:-` | 大きさを1段上げる、下げる。重ねると積み上がる（`:+++`） |
| `:!` `:%` | 悪いほう、良いほうのトーン。切り替えで、片方がもう片方を置き換える |
| `:*` | 強調。切り替え |
| `:@` | カスタムの区間。切り替え。文字が何を意味するかはアプリが決める |
| `::` | トーン、強調、カスタムの印を戻す。大きさは戻さない |

1つのクラスタに文字を組み合わせられます。`:!*` は悪いトーンで強調です。クラスタ
を2つ続けると意味が変わります。後ろの `:` が戻す記号として読まれるので、`:!:*`
では強調だけが残ります。

前に `:` がなければ、`+ - ! % * @` はただの文字です。

カスタムの区間は、文字全体がそのまま中身になります。中身は、たとえば URL や画像のパスです。

```dart
NaturalBlockParser.parse(':@https://example.com:@ を参照');
```

引数を取る中身は、`image(<source>)` と同じく `name(<引数>)` と書きます。
`payloadArgument(text, 'note')` は `note(...)` の括弧の中を返し、そうでない文字
なら null を返します。

### raw の区間

`` ` `` のフェンスで囲んだ文字は、書いたとおりに読みます。区切り、装飾、
エスケープは効きません。

```text
比較は`a == b`です

`
cat file.txt | grep foo | wc -l
`
```

- 中に改行がある区間はブロック（`RawNode`）、ない区間は文中（`RawSpanNode`）に
  なります。各フェンスにすぐ接する改行は落とします。
- 区間は、開いたときとちょうど同じ数のバッククォートの並びで閉じます。なので
  ``` `` ``` の中には、1つのバッククォートを書けます。
- 空の区間は何も作りません。閉じていない区間は文書の終わりまで続きます。

### エスケープ

バックスラッシュは、その場所で記号になるものだけをエスケープします。

- どこでも：`\:`、`` \` ``、`\\`
- 横並びの行と表の中：`\^`
- クラスタの中：装飾の文字すべて。エスケープはクラスタも終えるので、
  `:---\%%%` は -3 の大きさの `%%%` になります。
- 行頭とセルの頭：`\<`、`\=`、`\>`、`\^`、`\~`

それ以外の場所ではバックスラッシュはそのまま残るので、`C:\Users\you` はエスケープ
不要です。ただし、2つ続いたバックスラッシュは1つになります。`\\server` と書き
たいときは `\\\\server` と書きます。
