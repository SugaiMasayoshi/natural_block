# 設計メモ

構文が何をするかは README に、なぜそうしたかをここに書く。

## 記号

- 装飾は `:` の直後でだけ効く。`:` の付かない `+ - ! % ? * @` はただの文字なので、
  `C++`、`100%`、`Really?!`、`you@example.com` がそのまま書ける。
- 寄せの記号はブロックの先頭でだけ読む。だから `a > b`、`->`、`List<String>` は
  エスケープ不要。代償は文書の最初の文字で、そこの `=>` は中央寄せの `>` になる。
- 寄せの記号は1つだけ読む。寄せは値が1つなので、2つ目は矛盾しか生まない。
  装飾が連続して読むのは軸が複数あるから。
- セル区切りを `^`、中央寄せを `=` にした理由は3つ。
  - `<` `=` `>` は見て分かる組。`^`（上）では覚えるしかない。
  - `=` はありふれすぎる。実際の文書 207,217 行で `=` は 3.17%、`^` は 0.40% の行に
    出る。`=` を区切りにすると 5,016 行の普通の文が行に化けた
    （`x = 1`、`--flag=value`、URL のクエリ）。
  - フリック入力で `<` `=` `>` は同じキーにあり、向きが意味と一致する。

## レイアウト

- 空のブロックは残さず、空のセルは残す。行は幅を均等に分けるので、`左^^右` の
  空のセルが `右` を右端に押し出す。
- `|` は前のブロックを終える記号だ。行は `|A^B|` と先頭にも `|` を書く。省くと
  前の行が最初のセルに入る。`^` はセルを区切るだけで、ブロックは終えられない。
- 改行は区切りではなく文字で、木に行のノードはない。行ごとの構造を持つと、
  見出しやリストのような行単位の構文を足したくなるが、それは持たない。
- 空白は削らない。打った空白は見えるし消せる。

## 表

- 表は推測せず `~` で宣言させる。表の列は中身の幅で揃い、普通の行は幅を均等に
  分ける。どちらも必要なので、書き手に選ばせる。
- 表は中身であり、ブロックの中に入る。1つのブロックが文字・表・文字を持て、
  `|=` がすべてに効く。表は自分の寄せを持たず、含むブロックが配置する。
- 木は書かれたことだけを記録する。各セルは自分が書いた寄せだけを持ち、列の寄せ
  との解決や短い行を揃えるのは描く側の仕事。

## 装飾

- `:@...:@` は印を付けるだけで意味は言わない。文字がそのまま中身なので、知らない
  実装でも読める文字が残る。
- トーンは `negative` と `positive` の2つ。`:?`（info）は持たない。
  - どの文も情報なので、書き手が意図するものを表さない。
  - 初見の人に書いてもらった3つの文書で使われたのは1回だけで、それも余談を
    分けるためだった。それはブロックの仕事だ。
- 名前を色ではなく `Tone` にしたのは、書き手が言うのは良し悪しで、色は描く側が
  決めるから。

## raw

- raw がないと `cat file.txt | grep foo | wc -l` は3ブロックになり、コードが
  書けない。`|` を使う
  記号では文中に書けないので、常に効く文字として `` ` `` を足した。
- 閉じるのは開いたときと同じ数のバッククォートの並びだけ。これで言語自身の構文を
  引用できる。
- 中に改行があればブロック（`RawNode`）、なければ文中（`RawSpanNode`）。書いた
  場所では決めない。
- 閉じていないフェンスも文書の終わりまで raw になる。閉じない表と同じで、開く
  かどうかをフェンスだけで決めるため。

## 読み取り

- 各ノードが自分を読み、自分のものだけを消費する。区切りは親が食べ（文書と表は
  `|`、行は `^`）、囲む記号は囲まれるものが食べる（表は `~`、raw はフェンス）。
  新しい構文を足すときも、記号をどちらに属させるかで誰が読むかが決まる。

## テスト

- **グリッド**（`test/grid_test.dart`）：記号の文字の組を9つの文脈に書き（990組）、
  木の形を `test/grid/<文脈>.txt` と照合する。出力を変えるときは、差分を読んで
  意図した組だけが動いたのを確かめてから `dart run tool/update_grid.dart` で
  作り直す。読まずに作り直すと網にならない。
- **構文**（`test/syntax_test.dart`）：公開する構文の代表例を、値を含めた木全体で
  持つ。例を足すのは公開する構文だけ。
- **性質**（`test/property_test.dart`）：短い入力をすべて試し、どんな入力でも
  成り立つべきことだけを確かめる。
